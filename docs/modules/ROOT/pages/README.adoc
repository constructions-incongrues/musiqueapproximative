Cette documentation est générée avec https://antora.org/[Antora] et déployée automatiquement sur GitHub Pages.

== 🔧 Générer localement

=== Prérequis

* Node.js 20+
* npm

=== Installation

[source,bash]
----
npm install -g @antora/cli@latest @antora/site-generator@latest
----

=== Génération

[source,bash]
----
# Depuis la racine du projet
antora antora-playbook.yml

# Le site sera généré dans ./build/site
----

=== Prévisualisation

[source,bash]
----
# Avec un serveur HTTP simple
npx http-server build/site -p 8001

# Ou avec Python
cd build/site
python3 -m http.server 8001
----

Puis ouvrir http://localhost:8001

== ✍️ Contribuer à la documentation

=== Format

La documentation utilise https://asciidoc.org/[AsciiDoc], un format de markup plus puissant que Markdown.

=== Syntaxe de base

[source,asciidoc]
-----
= Titre de la page
:description: Description de la page

== Section niveau 2

=== Section niveau 3

Paragraphe de texte.

[source,bash]
----
# Bloc de code

echo "Hello"
----

* Liste à puces
* Item 2

.Tableau
[cols="1,2"]
|===
|Colonne 1 |Colonne 2

|Cellule 1
|Cellule 2
|===

xref:autre-page.adoc[Lien vers une autre page]

https://example.com[Lien externe]
-----

=== Ajouter une page

. Créer un fichier `.adoc` dans `docs/modules/ROOT/pages/`
. Ajouter une entrée dans `docs/modules/ROOT/nav.adoc`
. Commiter et pousser

Le site sera automatiquement régénéré et déployé.

== 🚀 Déploiement

Le déploiement est automatique via GitHub Actions :

. **Trigger** : Push sur `main` modifiant `docs/` ou `antora-playbook.yml`
. **Build** : Génération du site avec Antora
. **Deploy** : Publication sur GitHub Pages

Workflow : `.github/workflows/documentation.yml`
